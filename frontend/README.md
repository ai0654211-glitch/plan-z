# 🚀 PlanZ Ecommerce - متجر إلكتروني متكامل

متجر إلكتروني احترافي مبني بتقنيات حديثة تشمل React, Node.js, MongoDB

## 🌟 المميزات

- 🛍️ نظام متكامل لإدارة المنتجات
- 🛒 سلة تسوق ذكية
- 💳 نظام دفع آمن
- 📱 تصميم متجاوب
- 🔐 نظام مصادقة متقدم
- 🚀 أداء عالي
- 🐳 دعم Docker

## 🛠 التقنيات المستخدمة

### Frontend
- React 18
- Vite
- Tailwind CSS
- Context API

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- Mongoose

### DevOps
- Docker
- Docker Compose
- Nginx
